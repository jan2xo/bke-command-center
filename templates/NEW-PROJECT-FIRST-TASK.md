# BKE New Project — First Task Template

Use this as the first engineering task for every new BKE repository.

## Intent

Bootstrap the canonical BKE engineering instruction into this repository.

## Required source

Canonical file:

`jan2xo/bke-command-center/bke.md` from current `main`.

## Task checklist

- [ ] Read canonical `bke.md` from `jan2xo/bke-command-center` current `main`.
- [ ] Record the exact source commit SHA.
- [ ] Create root `bke.md` in this repository from that canonical source.
- [ ] Verify the local file is present and readable from the resulting exact head.
- [ ] Do not add `AGENTS.md` as the BKE instruction contract.
- [ ] Do not begin unrelated project engineering in this bootstrap intent.
- [ ] Record completion in the PR/issue with source SHA + resulting target head.

## Definition of done

The target repository contains root `bke.md`, sourced from the canonical BKE Command Center version, and future substantial engineering can begin from durable repository instructions without requiring ChatGPT Project memory or manual operator copying.
